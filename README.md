# BinaryText
 
> **Turn words into bits. And back.**

 
A clean, browser-based **UTF-8 Text ↔ Binary converter** with Unicode and emoji support.
 
### Features
 
- Text → Binary
- Binary → Text
- UTF-8 &amp; Unicode support
- Emoji support
- Instant conversion
- One-click copy
- Fully client-side &amp; private

 
### Tech
 
**HTML · CSS · JavaScript**
 
No backend. No dependencies. Just open `index.html` and start converting.
